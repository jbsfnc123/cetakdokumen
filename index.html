Bantuan & pintasan

Pintasan keyboard

  • Pindah mode 1 2 3 4
  • Simpan hasil mode aktif Ctrl + S
  • Tempel gambar ke halaman aktif Ctrl + V
  • Hapus gambar terpilih Delete
  • Geser gambar terpilih ← ↑ ↓ →
  • Geser lebih cepat Shift + panah
  • Batal pilih / tutup dialog Esc

Tentang format foto

  • JPG, JPEG, PNG, WebP, GIF, dan BMP didukung penuh. Format selain JPG/PNG otomatis dikonversi ke PNG sebelum dimasukkan ke PDF.
  • HEIC/HEIF (foto bawaan iPhone) tidak bisa dibaca browser. Ubah dulu ke JPG sebelum diimpor.

Catatan

  • Semua pemrosesan berjalan lokal di browser, file tidak pernah diunggah ke mana pun.
  • Library pdf-lib, pdf.js, dan JSZip masih dimuat dari CDN, jadi browser tetap butuh internet saat halaman dibuka.
  • Posisi gambar di mode Tempel Gambar tersimpan sementara di browser. Kalau fotonya sangat besar, penyimpanan sementara bisa penuh dan akan muncul peringatan.
